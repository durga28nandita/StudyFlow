# 💜 StudyFlow

### Plan Smarter. Study Better. Achieve More.

StudyFlow is a student productivity web application designed to make studying more organized and manageable. It brings task management, study planning, focus sessions, progress tracking, and performance analytics together in one place.

Built with React, JavaScript, and CSS, StudyFlow provides a clean interface with both Dark and Light themes.

🌐 **Live Demo:** https://study-flow-murex.vercel.app/

📂 **GitHub Repository:** https://github.com/durga28nandita/StudyFlow

---

## ✨ Features

- **Dashboard:** Get an overview of your study activities and daily goals.
- **Task Manager:** Create, organize, prioritize, and track study tasks.
- **Study Planner:** Plan study sessions and manage your schedule with a calendar.
- **Focus Timer:** Use focused study sessions to improve productivity.
- **Study Tracker:** Track your study progress and activities.
- **Analytics:** Visualize your productivity and study performance through charts.
- **Dark & Light Themes:** Switch between two themes with your preference saved.
- **Local Data Storage:** Your data is saved in your browser using LocalStorage.

## 🚀 Getting Started

Follow these steps to run StudyFlow locally.

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/durga28nandita/StudyFlow.git
   ```

2. Navigate to the project directory:

   ```bash
   cd StudyFlow
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 💾 Data Storage

StudyFlow currently uses browser LocalStorage to save user data.

This means data is stored locally in the browser and is not synchronized across different devices or users.
